# Governance

Este directorio contiene los artefactos de gobierno del laboratorio KOS-Lab.

## Contenido
- ADRs
- PRs de protocolo
- Tareas de arquitectura
- Registros de decisiones
- Discusiones y propuestas

## Convenciones
- Los identificadores de ADR siguen el formato `KOS-ADR-000001`.
- Las tareas siguen el formato `KOS-ARCH-Tarea-001` o `KOS-Lab-Tarea-001`.
- Los PRs de protocolo siguen el formato `KOS-PR-000001`.
