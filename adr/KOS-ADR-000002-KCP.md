# KOS-ADR-000002 — KOS Communication Protocol (KCP)

## Estado
Accepted

## Contexto
El laboratorio requiere un protocolo formal para la comunicación entre Operador, Supervisor y Delegados.

## Decisión
Se define KCP como el lenguaje operativo oficial de KOS para comandos, informes, eventos, consultas, respuestas y aprobaciones.

## Consecuencias
- El protocolo será independiente del Runtime.
- La interfaz operativa queda normalizada.
- Se facilita la trazabilidad entre decisiones, tareas, informes y ejecución.
