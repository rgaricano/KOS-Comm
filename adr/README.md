# ADR Index

Este directorio contiene los Architecture Decision Records (ADR) del laboratorio.

## Registro actual
- `KOS-ADR-000001` — Confidence Levels
- `KOS-ADR-000002` — KOS Communication Protocol (KCP)

## Plantilla
Cada ADR debe incluir:
- Identificador único
- Título
- Contexto
- Decisión
- Consecuencias
- Estado (Proposed / Accepted / Rejected / Superseded)
