# KOS-Lab Baseline 0.1

## Purpose

Refundar el repositorio como Repositorio Canónico de Ingeniería de KOS.

## Scope

Este baseline establece la estructura mínima del laboratorio para albergar:

- Canon
- Engineering
- Runtime
- Knowledge
- Context
- Storage
- API
- CLI
- Tests
- Tools
- Docs

## Invariants

- Trazabilidad obligatoria.
- Auditabilidad obligatoria.
- Persistencia canónica.
- No simulaciones salvo indicación explícita.
- Un único modelo canónico para ingeniería y conocimiento.
