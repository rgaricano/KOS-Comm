# KOS-Comm

KOS-Comm is the standalone repository for the communication architecture of KOS.

This repository originates from the historical **KOS-Comn** laboratory developed in `KOS-Lab`, but it establishes a new architectural generation based on explicit architectural boundaries, public contracts and capability engineering.

The historical KOS-Comn work is preserved as **Generation 1 (Foundation)**. The current development of KOS-Comm begins with **Generation 2**.

## Architectural generations

### Generation 1 — Historical foundation

The first generation established the historical KCA line:

- KCA — Knowledge Communication Architecture
- KRM — Knowledge Representation Model
- KEncoding — Knowledge Encoding
- KCP — Knowledge Communication Protocol
- KSCL — Knowledge Session Continuity Layer
- CP — Cognitive Projection

That line remains part of the architectural history and is preserved as the documented foundation from which this repository was extracted.

### Generation 2 — Boundary architecture

The second generation refactors KOS-Comm around architectural boundaries and public contracts.

The new engineering model is organized around:

- Architectural Boundaries
- Boundary Contracts
- Capability Specifications
- Normative Foundations
- Contract Integration
- Standard Publication
