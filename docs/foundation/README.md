# KOS-Comm Foundation

This directory preserves the reusable historical material that feeds Generation 2.

## What is preserved

- KCA — Knowledge Communication Architecture
- KRM — Knowledge Representation Model
- KEncoding — Knowledge Encoding
- KCP — Knowledge Communication Protocol
- KSCL — Knowledge Session Continuity Layer
- CP — Cognitive Projection
- Existing ADRs and baseline material that remain valid as historical or reusable reference

## What changes in Generation 2

Generation 2 reorganizes KOS-Comm around:

- Architectural Boundaries
- Boundary Contracts
- Capability Specifications
- Normative Foundations
- Contract Integration
- Standard Publication

## Purpose

The foundation layer is not the new architecture itself. It is the stable historical and reusable source from which the new architecture is extracted and specialized.
