# Transition Statement — Generation 1 to Generation 2

## Statement

KOS-Comm transitions from the historical KCA-based laboratory line (Generation 1) to a boundary-based communication architecture (Generation 2).

## Generation 1

Generation 1 is the historical foundation preserved for reuse and traceability. It includes:

- KCA
- KRM
- KEncoding
- KCP
- KSCL
- CP
- legacy ADRs and baseline documents that remain valid as historical reference

## Generation 2

Generation 2 is the active architectural generation for KOS-Comm. It is organized around:

- Architectural Boundaries
- Boundary Contracts
- Capability Specifications
- Normative Foundations
- Contract Integration
- Standard Publication

## Reuse rule

Generation 2 must reuse, reorganize, or specialize historical material whenever that material remains compatible.

Content is created only when the Generation 2 architecture introduces a concept that does not exist in the historical foundation.

## Authority rule

Generation 1 remains authoritative as historical source material.
Generation 2 becomes authoritative for the active repository model.

## Baseline rule

The first frozen baseline of Generation 2 is recorded in `BASELINE-G2-0.1.md`.
