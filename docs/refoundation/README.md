# KOS-Comm Refoundation

This branch refounds KOS-Comm as a second architectural generation.

## Generations

### Generation 1 — Historical foundation

Preserved from the KOS-Comn / KCA laboratory line:

- KCA — Knowledge Communication Architecture
- KRM — Knowledge Representation Model
- KEncoding — Knowledge Encoding
- KCP — Knowledge Communication Protocol
- KSCL — Knowledge Session Continuity Layer
- CP — Cognitive Projection

This generation remains part of the repository history and is kept as the documented foundation from which the refoundation is derived.

### Generation 2 — Boundary-based architecture

The refoundation reorganizes KOS-Comm around explicit architectural boundaries and public contracts.

The new engineering model is organized around:

- Architectural Boundaries
- Boundary Contracts
- Capability Specifications
- Normative Foundations
- Contract Integration
- Standard Publication

## Purpose

To establish a reproducible communication architecture with explicit boundaries, public contracts, verifiable integration and deterministic publication.
